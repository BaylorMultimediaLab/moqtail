# Capacity traces

One CSV per trace, header `t_s,rate_mbps`; each row holds the rate from `t_s`
until the next row. `example_4g.csv` is a synthetic placeholder so the trace
path can be exercised end to end. Replace it with real traces (for example the
Norway 3G/4G HSDPA datasets or the FCC broadband traces) converted to this
two-column form, and cite the source in the profile's `description`.
